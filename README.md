# SEREGA DROP(demo)

Автономный фронтенд на React, TypeScript, Vite и Tailwind CSS. Бэкенд и внешние платёжные сервисы не используются.

## Запуск

Нужен Node.js 22.12+ или совместимая более новая версия.

```bash
npm ci
npm run dev
```

Открыть адрес из вывода Vite. Для проверки сборки:

```bash
npm test
npm run build
npm run preview
```

Игрок: `player` / `player`. Локальная админка: `/admin`, пароль `admin`. Новые аккаунты начинают с 0 G. Для первого открытия пополнить виртуальный баланс через SEREGA PAY.

## Сценарии

- `/` (также `/upgrade`): апгрейд с инвентарём и полным каталогом; просмотр и выбор цели доступны гостю.
- `/cases`: 15 кейсов с индивидуальными вероятностями, анимированное открытие и результат.
- `/inventory`: поиск, сортировка, продажа отдельного экземпляра и выбор для апгрейда.
- `/history`: отдельный экран истории пополнений с суммой, способом, промокодом, бонусом и итогом.
- Апгрейд: выбор 1–6 экземпляров и цели дороже их суммы, подбор x2/x4/x8 и 35%/55%/75%, попытка и устойчивое окно результата.
- SEREGA PAY: 1 ₽ = 1,5 G, SEREGA добавляет 20%, лимит 10 000 G за день Europe/Minsk.
- `/admin`: создание и редактирование игроков, смена пароля, блокировка, баланс, выдача и изъятие экземпляра, история начислений.

Прогресс хранится в localStorage под ключом `serega-drop:demo:v1`. Сессии игрока и администратора хранятся в памяти и завершаются при перезагрузке. Данные принадлежат конкретному браузеру и origin; параллельное редактирование из нескольких вкладок не синхронизируется.

Пароли и административные проверки реализованы только для локальной демонстрации. Демо-пароли сохраняются открытым текстом в локальных данных. При подключении API авторизацию, случайный исход, баланс и проверки операций нужно перенести на сервер.

## Каталог

Снимок публичного каталога [StandoffCraft](https://standoffcraft.com/) от 15.11.2026: 2 383 записи, включая 464 StatTrack-варианта; 7 редкостей и 1 924 уникальных изображения. Все записи, возвращённые источником, сохранены. Souvenir-варианты в этом снимке источник не вернул. Полнота относительно самой игры отдельно не подтверждена.

- `public/assets/catalog-source.json`: исходные ID, названия, редкости, ссылки и остальные поля референса.
- `src/api/catalog-data.json`: локальный каталог интерфейса; к имени варианта добавляется видимая отметка StatTrack/Souvenir.
- `public/assets/skins/`: изображения, доступные без запросов к референсу.
- `public/assets/download-report.json`: отчёт загрузки; пропущенных изображений нет.
- `scripts/import-catalog.py`: пересборка локального каталога и восстановление отсутствующих изображений из сохранённого снимка (`python3 scripts/import-catalog.py`).

Названия, изображения и редкости взяты из источника. Цены назначены стабильно по ID внутри диапазонов из BACKEND_PLAN.md; это виртуальная демо-экономика, а не рыночные цены референса. Витрина содержит 15 кейсов стоимостью от 49 до 1 999 G. Базовый шанс хорошего дропа — предмета не дешевле цены кейса — равен 15%. После трёх промахов по конкретному кейсу он скрыто повышается на 3 п.п. за открытие до 35%, поэтому средняя частота составляет примерно одно хорошее открытие из пяти. Предмет дешевле 20% цены кейса показывается с шансом 1%; остальные базовые вероятности отображаются в составе. Право публичного распространения ассетов отдельно не проверялось; деплой не выполнялся.

## Подключение бэкенда

`src/api/demo.ts` содержит локальный адаптер операций, `src/api/types.ts` — типы данных, `src/api/economy.ts` — расчёты в целых сотых G. Экраны получают сервис через `src/app/context.tsx`. Для подключения бэкенда заменить этот адаптер после согласования OpenAPI из BACKEND_PLAN.md; текущая версия не отправляет HTTP-запросы к API.

`vercel.json` содержит SPA fallback для прямых переходов на `/cases`, `/admin`, `/inventory`, `/history` и `/upgrade`.

## Проверка

26 автоматических тестов проверяют начисления, неизвестный код, границы суток, лимит и неизменность данных при отказе, 15 кейсов, сумму вероятностей, базовый шанс хорошего дропа, мягкий pity и шанс дешёвых предметов, отдельные копии, сохранение прогресса, оба исхода апгрейда и разграничение ролей. Для нескольких экземпляров проверены расходование 6 с сохранением седьмого, дубли, недоступные ID и отказ без частичного списания. Геометрические тесты проверяют сектор с центром 180°, остановку указателя в секторе нужного исхода и разные точки внутри правильной карточки кейса.

До изменения анимаций в браузере проверены вход, начисление 900 G за 500 ₽ с SEREGA, открытие Starter, продажа, админка, выдача предмета, история платежей и апгрейд. Проверена ширина 360 CSS-пикселей без горизонтального переполнения на главной и апгрейде.

Анимации и мультивыбор от 15.11.2026 визуально не проверялись: владелец выбрал работу без Computer Use. Используется одна исходная анимация: апгрейд длится 5,2 секунды и делает 5 оборотов, кейс — 6 секунд. Событие окончания движения открывает результат, который остаётся до действия игрока. В режиме уменьшенного движения результат показывается сразу. Исход фиксируется локальным адаптером перед анимацией; анимация не меняет вероятность.
