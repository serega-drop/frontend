# SEREGA DROP(demo)

Фронтенд для виртуального симулятора с отдельным API. Для локальной разработки доступны автономная демо-версия и HTTP-клиент.

## Запуск

Нужен Node.js 22.12+ или совместимая более новая версия.

```bash
npm ci
npm run dev
npm test
npm run build
```

При локальном запуске через `npm run dev` без `VITE_API_URL` работает демо. Игрок входит как `player` / `player`, администратор на `/admin` с паролем `admin`. Создайте заявку через SEREGA PAY, одобрите её во вкладке «Заявки» и откройте кейс под игроком. Данные демо хранятся в localStorage под `serega-drop:demo:v1`, независимые сессии демо в sessionStorage. Демо использует локальный каталог и приближённый подбор бонусных наборов.

Сборка `npm run build` по умолчанию обращается к `/api/v1` на origin фронтенда. `vercel.json` направляет этот путь на Render перед SPA fallback. На Render задайте `FRONTEND_ORIGIN=https://serega-drop.vercel.app` и `COOKIE_SECURE=true`. Access JWT находятся в памяти и восстанавливаются через отдельные refresh cookies игрока и администратора.

Для локальной проверки HTTP запустите backend с `FRONTEND_ORIGIN=http://127.0.0.1:5173` и `COOKIE_SECURE=false`. Команды миграции и импорта находятся в README backend-репозитория.

```bash
API_PROXY_TARGET=http://127.0.0.1:8000 VITE_API_URL='' npm run dev -- --host 127.0.0.1
```

Для HTTP-режима с другим адресом можно указать origin API без `/api/v1` в `VITE_API_URL`. Пустое значение включает запросы к origin фронтенда. Для `npm run preview` прокси использует Render по умолчанию, локальный адрес задаётся через `API_PROXY_TARGET`.

## Граница API

Сценарии в `src/features/` получают `GameClient` через `src/app/context.tsx`. `src/api/client.ts` описывает клиентские типы, `src/api/http.ts` собирает запросы и обновляет данные из ответов. Спецификация сервера и экономика находятся в `BACKEND_PLAN.md` рядом с репозиториями.

- Пути начинаются с `/api/v1`. Пагинация принимает `page` с 1 и `page_size`, ответы содержат `items` и `total`. Денежные значения с суффиксом `_minor` хранятся в сотых G.
- `/auth/login`, `/admin/login` и refresh соответствующей роли возвращают `access_token`. Refresh cookies раздельны. Logout отзывает только выбранную роль. Ошибки содержат `code` и `message`.
- `/inventory/sales/quote` принимает `mode` и массив `inventory_item_ids`. Режим `all` получает весь инвентарь у сервера. Ответ содержит `quote_id`, список ID и сумму. Подтверждение отправляет `quote_id`, результат содержит `sold_ids` и `balance_minor`.
- `/upgrades/quote` принимает ID экземпляров и цель, желаемый процент или множитель. Ответ содержит `quote_id`, `target` и `chance`. Игровой ответ дополнительно возвращает `awarded_items`, `balance_minor`, итог и геометрию для анимации. Ответ открытия кейса содержит `item` и `balance_minor`.
- Читающие и изменяющие операции разделены. Повтор POST после недоступности сети или 5xx использует прежний `Idempotency-Key` для того же запроса в открытой вкладке. Конфликт котировки 409 требует нового подтверждения.
- Для недоступного промокода при одобрении вернуть `promo_unavailable`. Явное базовое одобрение отправляется с `decision: "approve_base"`.
- Опасная зона получает `version`, `active` и `defaults`, отправляет версию на изменение или сброс и принимает конфигурацию из ответа сервера. Активная версия не пересчитывает завершённые операции.

## Звуки

В `public/audio/` пять оригинальных звуков. Звон запускает обычный и бонусный спин апгрейда. Тихий щелчок звучит при прохождении отметок колеса и карточек ленты под указателем. У дропа кейса, награды апгрейда и проигрыша отдельные окончания одного сигнала. Значок динамика отключает звуки и сохраняет выбор в браузере. Режим уменьшенного движения сразу раскрывает итог.

## Ассеты

Демо-снимок `src/api/catalog-data.json` содержит 2 383 записи. Изображения в `public/assets/skins/` загружаются отложенно. В HTTP-режиме сервер возвращает собственные ID, цены и локальные пути изображений. Свежий снимок цен StandoffCraft хранится рядом с репозиториями и предназначен для серверного импорта. При отсутствии локального файла показывается заглушка.
